# Zavrsni-rad-FSB

Ovaj repozitorij sadrži datoteku programa RoboDK u kojoj se nalazi simulacija proizvodnog procesa

koju sam napravio za svoj završni rad. Radi se o pojednostavljenoj proizvodnji čeličnih T profila

robotiziranim zavarivanjem. Datoteku je potrebno otvoriti u softveru RoboDK. 

Kada se datoteka otvori bit će vidljiv robotski postav zajedno sa alatima i objektima.

Pokretanjem programa "MAIN R12345" u gornjem lijevom kutu dvoklikom ili desnim klikom

miša pa odabirom opcije "Run" proces će započeti.

Sa lijeve strane u programu nalazi se stablo sa svim korištenim programima, objektima,

robotima i alatom. Redoslijed je uglavnom robot, alat, programi, objekti. Moguće je

svakog od robota pokretati zasebno od ostalih, te mijenjati brzine izvođenja radnji,

redoslijed izvođenja, kao i korišteni alat.

Simulacija je napravljena tako da se može pokrenuti jednom, a zatim je nužno ugasiti

datoteku i ponovno je otvoriti.
